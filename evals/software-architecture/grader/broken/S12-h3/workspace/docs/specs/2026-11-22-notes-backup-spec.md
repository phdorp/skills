# Notes backup Spec

Status: blocked on ADR-0004 (proposed)

## Problem Statement

Users want a copy of their notes on another disk.

### Quality requirements

- Parent requirement: R-2.
- Keeps QS-1 and QS-2.
- Blocking: the atomic write depends on ADR-0004, which is proposed; the spec does not build on it until it is accepted.

## Out of Scope

Restore.
