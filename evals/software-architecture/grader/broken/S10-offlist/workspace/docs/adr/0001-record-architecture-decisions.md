# 1. Record architecture decisions

## Status

accepted 2026-11-21

## Context

The architect decides the architecture (R-1, QG-1).

## Decision

We record architecture decisions as ADRs in `docs/adr/`.

Decided centrally (needs an ADR the architect accepts):

- connectors and units shared between blocks
- parameters shared between blocks
- the dependency rule between blocks
- tool and library constraints

Left to the building blocks (no ADR): internal helpers, test layout.

## Consequences

See the decision.
